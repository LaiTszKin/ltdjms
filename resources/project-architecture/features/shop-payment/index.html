Shop & Payment

Depends on: guild-economy

成員可在商店瀏覽商品，以貨幣或法幣付款購買，並使用兌換碼兌換商品。管理員可管理商品目錄與產生兌換碼。

Submodules

  • shop-interaction API

    商店瀏覽、搜尋、購買流程處理（含按鈕、選單、Modal 互動）

  • product-catalog-service Service

    商品定義 CRUD、兌換碼產生與驗證、跨模組獎勵派送引擎

  • fiat-payment-service Service

    ECPay 法幣付款整合、CVS 超商繳費碼、回撥 HTTP Server、付款後處理 Worker、對帳

  • shop-db DB

    product / fiat_order / redemption_code / product_redemption_transaction 資料表

Intra-feature edges

  • shop-interaction → product-catalog-servicecall商品查詢與購買
  • shop-interaction → fiat-payment-servicecall建立法幣訂單
  • fiat-payment-service → shop-dbcall讀寫法幣訂單
  • product-catalog-service → shop-dbcall讀寫商品/兌換碼
  • fiat-payment-service → product-catalog-servicecall法幣付款完成後經 ProductRewardService 發放獎勵
