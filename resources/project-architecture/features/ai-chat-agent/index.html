AI Chat & Agent

成員在允許頻道提及 @bot 可獲得 AI 回覆或啟動 Agent 執行 Discord 管理工具。管理員可設定頻道白名單與 Agent 啟用。

Submodules

  • ai-mention-interaction API

    @bot 提及監聽、AI 聊天 vs Agent 路由決策、串流回覆輸出

  • ai-chat-service Service

    AI 串流回覆（LangChain4j）、頻道白名單檢查、提示詞系統提示載入

  • ai-agent-service Service

    Agent 工具執行（17 個 Discord 管理工具）、對話記憶、工具審計日誌

  • markdown-validation Pure fn

    AI 回覆 Markdown 語法校驗與自動修正管線（CommonMark 解析器 + 13 道 Regex 修復）

  • ai-db DB

    ai_channel_restriction / ai_agent_channel_config / tool_execution_log 資料表

Intra-feature edges

  • ai-mention-interaction → ai-chat-servicecall路由至 AI 聊天
  • ai-chat-service → ai-agent-servicecallAgent 模式啟用時路由至工具執行
  • ai-chat-service → markdown-validationcall串流回覆 Markdown 校驗
  • ai-chat-service → ai-dbcall讀寫頻道白名單
  • ai-agent-service → ai-dbcall讀寫 Agent 設定與工具日誌
