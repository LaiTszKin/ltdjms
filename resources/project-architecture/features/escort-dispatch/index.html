Escort Dispatch

Depends on: shop-payment

管理員可為護航人員派單，護航人員確認接單後完成服務，客戶可請求售後。支援從商店購買自動建立派遣單。

Submodules

  • dispatch-interaction API

    派遣面板指令、私訊流程、狀態轉換按鈕處理

  • dispatch-service Service

    訂單狀態機（7 階段）、自動超時完成、跨模組 Handoff、售後人員管理、護航選項定價

  • dispatch-db DB

    escort_dispatch_order / guild_escort_option_price / dispatch_after_sales_staff 資料表

Intra-feature edges

  • dispatch-interaction → dispatch-servicecall委派派遣業務
  • dispatch-service → dispatch-dbcall讀寫派遣訂單
