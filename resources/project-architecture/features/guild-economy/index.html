Guild Economy

成員可以在 guild 內查詢餘額、參與骰子遊戲賺取貨幣。管理員可設定貨幣名稱與圖示。雙軌經濟：guild 貨幣（用於購物）與遊戲代幣（用於遊玩），遊戲獎勵以貨幣發放。

Submodules

  • economy-interaction API

    Discord 指令處理層：貨幣設定、擲骰遊戲、交易查詢

  • economy-service Service

    雙軌經濟核心邏輯：貨幣帳戶、代幣帳戶、交易記錄、遊戲獎勵結算

  • economy-db DB

    guild_currency_config / member_currency_account / game_token_account / dice_game_config / transaction 資料表

Intra-feature edges

  • economy-interaction → economy-servicecall委派業務邏輯
  • economy-service → economy-dbcall讀寫貨幣/代幣帳戶
  • economy-service → economy-interactionreturnBalanceView / GameResult
