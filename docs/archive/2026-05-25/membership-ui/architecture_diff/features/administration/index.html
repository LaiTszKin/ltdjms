Administration

Depends on: guild-economy, shop-payment, escort-dispatch, ai-chat-agent

管理員透過管理面板設定貨幣經濟參數、管理商品與兌換碼、配置 AI 與護航規則。一般成員透過會員面板查餘額、交易記錄與歷史。

Submodules

  • admin-panel-interaction API

    管理面板指令、按鈕、Modal，含產品管理、AI 設定、護航設定子面板

  • user-panel-interaction API

    已遷移至 @ltdjms/user-panel；1:1 對齊 Java user_panel_* customId 與 embed 結構

  • panel-service Service

    面板業務邏輯 Facades，彙整經濟、AI、派遣、商品設定與即時事件更新

  • notifications Service

    跨模組通知：買家付款成功 DM、管理員新訂單通知、護航/售後私訊

  • membership-admin-ui API

    Admin panel 會員等級管理子面板

Intra-feature edges

  • admin-panel-interaction → panel-servicecall委派管理操作
  • user-panel-interaction → panel-servicecall會員資訊查詢
  • panel-service → notificationscall觸發訂單/付款通知
