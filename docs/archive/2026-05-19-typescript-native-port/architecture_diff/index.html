LTDJMS — Discord Bot 專案架構

基於 Java/JDA 的 Discord bot，在單一 guild 內承載經濟互動、商品交易、護航協作與 AI 頻道治理。涵蓋 guild 貨幣與遊戲代幣的雙軌經濟系統、商品商店與法幣付款（ECPay）、護航派單狀態機、AI 聊天與 Agent 工具執行、以及管理面板。掃描範圍：src/main/java/ltdjms/discord/ 下所有業務模組與共用基礎設施。

Submodule index

  • Guild Economy economy-interaction API

    Discord 指令處理層：貨幣設定、擲骰遊戲、交易查詢

  • Guild Economy economy-service Service

    雙軌經濟核心邏輯：貨幣帳戶、代幣帳戶、交易記錄、遊戲獎勵結算

  • Guild Economy economy-db DB

    guild_currency_config / member_currency_account / game_token_account / dice_game_config / transaction 資料表

  • Shop & Payment shop-interaction API

    商店瀏覽、搜尋、購買流程處理（含按鈕、選單、Modal 互動）

  • Shop & Payment product-catalog-service Service

    商品定義 CRUD、兌換碼產生與驗證、跨模組獎勵派送引擎

  • Shop & Payment fiat-payment-service Service

    ECPay 法幣付款整合、CVS 超商繳費碼、回撥 HTTP Server、付款後處理 Worker、對帳

  • Shop & Payment shop-db DB

    product / fiat_order / redemption_code / product_redemption_transaction 資料表

  • Escort Dispatch dispatch-interaction API

    派遣面板指令、私訊流程、狀態轉換按鈕處理

  • Escort Dispatch dispatch-service Service

    訂單狀態機（7 階段）、自動超時完成、跨模組 Handoff、售後人員管理、護航選項定價

  • Escort Dispatch dispatch-db DB

    escort_dispatch_order / guild_escort_option_price / dispatch_after_sales_staff 資料表

  • AI Chat & Agent ai-mention-interaction API

    @bot 提及監聽、AI 聊天 vs Agent 路由決策、串流回覆輸出

  • AI Chat & Agent ai-chat-service Service

    AI 串流回覆（LangChain4j）、頻道白名單檢查、提示詞系統提示載入

  • AI Chat & Agent ai-agent-service Service

    Agent 工具執行（17 個 Discord 管理工具）、對話記憶、工具審計日誌

  • AI Chat & Agent markdown-validation Pure fn

    AI 回覆 Markdown 語法校驗與自動修正管線（CommonMark 解析器 + 13 道 Regex 修復）

  • AI Chat & Agent ai-db DB

    ai_channel_restriction / ai_agent_channel_config / tool_execution_log 資料表

  • Administration admin-panel-interaction API

    管理面板指令、按鈕、Modal，含產品管理、AI 設定、護航設定子面板

  • Administration user-panel-interaction API

    會員面板指令與按鈕：餘額查詢、交易記錄、兌換碼輸入

  • Administration panel-service Service

    面板業務邏輯 Facades，彙整經濟、AI、派遣、商品設定與即時事件更新

  • Administration notifications Service

    跨模組通知：買家付款成功 DM、管理員新訂單通知、護航/售後私訊

  • Shared Infrastructure discord-api External

    Discord.js 抽象層：domain 介面、discord.js adapter、mock 實作、Embed/Button/SelectMenu 工具 (替代 JDA)

  • Shared Infrastructure event-bus Service

    同步領域事件匯流排：EventEmitter-based DomainEventPublisher (替代 CopyOnWriteArrayList Consumer)

  • Shared Infrastructure cache-layer Service

    Redis 快取抽象 (ioredis 替代 Lettuce)：CacheService 介面、RedisCacheService、NoOpCacheService

  • Shared Infrastructure di-container Service

    tsyringe 依賴注入容器 (替代 Dagger)：@singleton/@inject 裝飾器、container.resolve

  • Shared Infrastructure di Service

    DI container (tsyringe, 替代 Dagger)

  • Shared Infrastructure database Service

    Drizzle ORM + node-postgres 資料庫層 (替代 JOOQ/JDBC/HikariCP/Flyway)：連線池、migration runner、schema 定義

  • Shared Infrastructure config Service

    Zod + dotenv 組態管理 (替代 Typesafe Config)：EnvironmentConfig、env loader、schema validation

  • Shared Infrastructure logging Service

    pino 結構化日誌 (替代 SLF4J/Logback)：JSON 輸出、child logger、level 控制

  • Shared Infrastructure types Pure fn

    核心型別系統：Result<T,E>、DomainError (27 categories)、DomainEvent (12 types)
