Membership Tiers

全域 Discord User ID 會員等級：護航法幣消費評級、結算日重算、付款折扣、贈幣與個人面板展示。

Submodules

  • tier-config Pure fn

    等級常數、MembershipTierEvaluator 純函式判定

  • membership-db DB

    global_member_membership 主表與 repository

  • join-tracking API

    GuildMemberJoin 監聽、最早加入日與結算錨點

  • spend-ledger Service

    法幣護航付款 M 寫入 spend entry

  • settlement Service

    結算排程、月平均 M、等級重算

  • payment-discount Service

    MembershipPricingService 付款折扣

  • benefits-ui UI

    結算贈幣 + user-panel 等級展示

  • admin-membership Service

    MembershipAdminService 管理員調整 spend M 與 tier

Intra-feature edges

  • admin-membership → spend-ledgercallInsert ADMIN_ADJUST entry
  • admin-membership → membership-dbcallUpdate current_tier
